Documentación del Desarrollo del Proyecto

1. Descripción General y Objetivos

Este proyecto implementa un sistema inteligente para la estimación y análisis del flujo vehicular urbano. Utilizando un modelo predictivo basado en Machine Learning, la plataforma procesa variables meteorológicas y temporales para anticipar niveles de congestión vial y optimizar la toma de decisiones operativas.

2. Pipeline de Datos y Entrenamiento

  • Dataset Base: Extracción de datos históricos de tráfico (DataBase-trafic analitic.csv).
  • Variables Analizadas: Hora del día, día de la semana, temperatura, precipitaciones y volumen vehicular estimado.
  • Modelo Seleccionado: RandomForestRegressor en Python (Google Colab), seleccionado por su alta robustez frente a relaciones no lineales entre el clima y la densidad de tráfico.

3. Arquitectura y Despliegue (CI/CD)

La aplicación está estructurada para garantizar despliegue continuo:

  • Control de Versiones: Repositorio oficial alojado en GitHub.
  • Hosting de la Landing Page: Despliegue automático en producción mediante Netlify.
  • Inteligencia Artificial Conversacional: Implementación de una custom skill de Gemini para interpretar las métricas técnicas del modelo en lenguaje natural.
